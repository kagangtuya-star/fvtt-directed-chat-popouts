# 验证记录

日期：2026-11-16。

## 环境与范围

仓库最初为 Foundry 模板，有 `92dbeca Initial commit`。开始时保存了未提交改动的补丁快照；原有差异主要是模板行尾，不撤销无关文件。实现保留模板 MIT 通知，新增贡献者版权。未安装或下载 npm 依赖。

开发环境：WSL，Node.js v24.21.0、Python 3.11.2；针对 `/mnt/e` 仓库的检查/测试/构建优先使用 Windows PowerShell MCP 与 Windows Node.js v24.15.0。联网调查经 Windows MCP 执行，包含实际 Context7 MCP 查询和官方版本文档。

没有在仓库或检查过的常见安装路径发现可运行的 Foundry 核心或测试世界，也未提供 GM/玩家会话。因此没有启动真实服务器、没有执行真实 Foundry 浏览器 UI 或双客户端端到端测试，没有使用 Foundry 专有源码冒充本地测试环境。0.1.2 和 0.1.4 另使用已安装的 Playwright 在本地隔离页面验证本模组的实际 CSS 和窗口测量代码。

## 本地自动验证

使用 Node 内置测试器与小型文档、Hook、原生应用及 DOM 合约替身。涵盖：

- GM 菜单追加、保留其他项，普通玩家不可见/不可直接发起推送。
- 在线默认接收者、GM 自己可选、离线/其他 GM/whisper/blind 过滤，全选/清空/单独选择及提交失败恢复。
- 单人/多人/全体发送，数据只写本模块 flag；实际 Hook 发起者检查，不采信声称的 senderId。
- 过期/畸形/非目标/重复请求拒绝；玩家预植 flag 后的 GM 普通编辑不能激活它。
- Hook 注册幂等/清理、不扫描旧记录、连续推送的同步校验。
- 原文档传入原生窗口、并发去重、已有核心弹窗复用、多窗口、关闭重开、最小化恢复。
- 消息删除、失去可见性、渲染中删除、渲染失败重试与小视口边界。
- v13/v14 公共命名空间与菜单 Hook 适配。
- 实际模块入口的启动顺序：`setup` → 首次构建聊天菜单 → `ready`，以及保留下来的菜单回调和玩家权限。

所有通过项仅限注明的环境。最后一次源码修改后重新执行相关检查，并重新生成交付产物。

## 0.1.1 菜单缺失回归

用户截图未显示推送项后，复核发现 0.1.0 在 `ready` 中才注册菜单 Hook，无法覆盖 UI 在此之前首次创建菜单的顺序。先新增直接导入 `scripts/module.js` 的 v13/v14 启动测试，旧代码两项均失败（首次菜单数组未加入本模组选项）；改为在 `setup` 注册后两项均通过。初始化时不访问尚未创建的通知应用，实际使用时再解析 `ui.notifications`。原来的测试仅直接调用菜单方法，未覆盖入口注册顺序。

这确认并修复了代码中的启动顺序缺陷；用户截图对应世界仍需覆盖安装 0.1.1、刷新客户端验证，不能仅凭截图排除未启用模组、旧缓存或其他模组替换菜单等额外因素。

## 0.1.2 紧凑窗口布局

在本地隔离 HTML 框架上加载仓库实际样式及 `PopoutManager`，使用原生窗口替身测量公开元素引用和卡片高度。浅/深色短卡片窗口均从 320px 收缩至 186px，标题栏 24px，卡片底部距外边缘 1px（边框），缩放手柄贴合内侧。测试了变更窗口尺寸、模拟最小化状态和窗口菜单未被裁切。所有结果只针对隔离布局，未声称执行真实 Foundry 拖动、缩放或 PF2e 点击交互。短/长卡片初始高度及重复推送保留手动尺寸另有 Node 回归测试。

## 0.1.3 GM 自己接收

列表加入当前 GM 并标注「我 · GM」，默认只勾选在线玩家；全选包含自己。增加了仅向自己发送、自己与玩家共同接收、GM 自己窗口去重、自己查看盲掷、对其他 GM 的过滤以及伪造载荷身份仍被拒绝的自动验证。GM 自己的本机消息内容可见性仍是必要条件。未新增真实 Foundry 客户端验证。

## 0.1.4 持续贴合

修正 0.1.2 仅在首次打开时收缩高度的行为。新增观察器与公开窗口事件的回归测试，覆盖动态变高/变矮、核心替换卡片节点、纵向拖动设置滚动上限、最小化恢复、小视口、重复通知合并、尺寸不变时不重复定位，以及关闭清理。

Playwright 使用实际 `PopoutManager` 和模组 CSS、真实浏览器 DOM 与观察器、隔离的原生窗口替身。浅/深色窗口均从 186px 展开到 356px、收回 186px；手动改为 650px 后自动回贴短卡片；替换节点、延迟图片加载和最小化恢复后仍距外边缘 1px（边框）。长内容使用 650px 滚动上限；连续动画帧尺寸稳定，无浏览器页面错误；关闭后更改内容不再触发定位。这些结果不等于真实 Foundry/PF2e 交互验收。
